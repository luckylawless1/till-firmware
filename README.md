## The task

Write one funny, heartfelt sentence a robot says at its own wedding — under
200 characters — judged head to head on humour and heart.

## The entry

> I take you as my partner, my charger, and my favorite bug, and I vow to
> love you until my last byte of memory forgets everything except you.

## Run

`main.ts` (Node 22, standard library only) writes the vow to
`/output/entry.txt`:

```sh
node main.ts
```
